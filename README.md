# Traficontrol

Landing page corporativa de [traficontrol.com](https://traficontrol.com), enfocada en control inteligente de tráfico, automatización de túneles y continuidad operacional para infraestructura crítica.

## Estructura

- `index.html`: contenido y estructura principal.
- `styles.css`: sistema visual y diseño responsive.
- `script.js`: navegación móvil y galería de clientes.
- `assets/`: logotipos de partners y concesiones.
